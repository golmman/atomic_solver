## Contents

- `env.json` — commit, host, toolchain.
- `state/greps_before.txt` / `state/greps_after.txt` — the Phase 0 dead-code
  greps (`dump_to_bin`, `DumpToBin`, `ProofEvent::Clear`, `Position::default`)
  before and after; the after file also pins the single-variant `ProofEvent`
  and the documented `clippy::new_without_default` allow.
- `state/linecounts_before.txt` / `state/linecounts_after.txt` — `wc -l` /
  `wc -c` for the touched files.
- `state/gate_before.txt` / `state/gate_after.txt` — test counts and wall
  time of the fast gate.
- `state/anchors.txt` — the three search anchors (quick @ 256, dec31 FO,
  m22 FO) and the proof-tree dump sha256, before and after.

No solver transcripts and no TT snapshots are committed; the mate-in-3
snapshot used for the dump-identity check is regenerated by the command
below (`/tmp`, deleted afterwards).

## Reproduce

```bash
cargo build --release --all-targets

# search anchors
./target/release/examples/benchmark --suite quick --first-outcome \
  --timeout 3 --runs 1 --tt-size 256 --json
./target/release/atomic_solver \
  --fen 'r1bq1k2/ppN3p1/2p1p2P/6P1/1b1P1p2/8/PP3P2/R2K1B1R b - - 0 15' \
  --timeout 20 --first-outcome
./target/release/atomic_solver \
  --fen '4r2k/3p4/2pB2p1/p6p/5pPP/2N1PP2/P1PP4/1R4RK w - - 0 22' \
  --timeout 60 --first-outcome

# proof-tree dump identity (worker finalize path)
./target/release/atomic_solver --fen '4k3/8/8/8/8/8/8/4KRR1 w - - 0 1' \
  --timeout 5 --tt-dump-path /tmp/mate3.tt
./target/release/examples/reconstruct_pt --snapshot /tmp/mate3.tt \
  --out /tmp/dump.bin && sha256sum /tmp/dump.bin

# gate
cargo test --release
```
