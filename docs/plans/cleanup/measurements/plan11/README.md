## Contents

- `env.json` — commit, host, toolchain.
- `dup_census.py` — the Phase C duplicate-block census driver (normalized
  `difflib` block diff of `examples/common.rs` vs `tests/common/mod.rs`,
  blocks of ≥ 2 lines only; `HEAD` reads the committed copies, `WORKTREE`
  the files as they stand).
- `state/linecounts_before.txt` / `state/linecounts_after.txt` — `wc -l` /
  `wc -c` for every touched file (before = `git show HEAD:<path>`).
- `state/greps_before_after.txt` — the field-name census, the
  win-in-1-fixture-FEN and `M19_FEN` copy counts, the `--experiment`
  grep, and the removed-symbol grep.
- `state/duplication_report.txt` — the census output before/after
  (45 duplicated normalized lines → 2).
- `state/anchors.txt` — the three search anchors from `plan8.md` §Phase 0
  plus the plan10 proof-tree dump sha256, re-measured after the change.
- `state/reconstruct_dump.txt` — the surviving `reconstruct_pt
  --snapshot` run's stdout and dump sha256 (Phase E regression check).
- `state/gate_before.txt` / `state/gate_after.txt` — fast-gate test counts
  and wall time, with the proofdb targets broken out.

No solver transcripts and no TT snapshots are committed; the mate-in-3
snapshot used for the dump-identity check is regenerated by the command
below (`/tmp`, deleted afterwards).

## Reproduce

```bash
cargo build --release --all-targets

# Phase C duplication census (before = HEAD, after = working tree)
python3 docs/plans/cleanup/measurements/plan11/dup_census.py HEAD \
  examples/common.rs tests/common/mod.rs
python3 docs/plans/cleanup/measurements/plan11/dup_census.py WORKTREE \
  examples/common.rs tests/common/mod.rs

# search anchors
./target/release/examples/benchmark --suite quick --first-outcome \
  --timeout 3 --runs 1 --tt-size 256 --json
./target/release/atomic_solver \
  --fen 'r1bq1k2/ppN3p1/2p1p2P/6P1/1b1P1p2/8/PP3P2/R2K1B1R b - - 0 15' \
  --timeout 20 --first-outcome
./target/release/atomic_solver \
  --fen '4r2k/3p4/2pB2p1/p6p/5pPP/2N1PP2/P1PP4/1R4RK w - - 0 22' \
  --timeout 60 --first-outcome

# proof-tree dump identity (the surviving reconstruct_pt path)
./target/release/atomic_solver --fen '4k3/8/8/8/8/8/8/4KRR1 w - - 0 1' \
  --timeout 5 --tt-dump-path /tmp/mate3.tt
./target/release/examples/reconstruct_pt --snapshot /tmp/mate3.tt \
  --out /tmp/dump.bin && sha256sum /tmp/dump.bin

# gate
make test
```
